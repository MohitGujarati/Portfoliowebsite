# Mohit Gujarati — a portfolio you can talk to

## Planning rubric
1. Product: Mohit's developer portfolio presents his mobile, web, AI projects, experience, and research to recruiters and collaborators.
2. Strongest source line: “I build … that ship.” This film makes no years-of-experience or performance claims.
3. Hook: an actual mohit-sh command prompt types `whoami` and answers with Mohit's identity.
4. Real UI: source-rendered Terminal and CodeCard components, project names and technologies from lib/site.ts, original CSS and fonts.
5. Length: 22 seconds, enough for a readable terminal interaction, identity reveal, three projects, and contact invitation.
6. Tone: polished; a developer's interactive calling card. Dark graphite, lime, restrained motion.
7. Audio: bundled steady instrumental, sparse soft typing/landing accents, no narration.
8. Caption: “I built a portfolio with its own command line. Explore my mobile, web and AI projects—and try the terminal.”
9. Flow: open terminal → type whoami → see identity → explore project work → contact invitation. The video simulates this real interaction deterministically for rendering.

## Format and source
Vertical 1080 × 1920, 30 fps. Source project: ../. Notion guide's vertical polished /brag workflow. Public professional identity is the subject authorized by the user. No environment files, keys, customer information, or private data are used. Contact uses the public portfolio URL from README rather than an email.
